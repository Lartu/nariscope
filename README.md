# Nariscope

A native macOS Gopher browser written in Swift. The browser uses a simple heuristic to render Gopher sites in a variable-width layout (although you can switch to a fixed-width view if you want to). This makes browsing the Gophersphere much friendlier and easier to read, at least for me. It also supports most features you'd expect from a modern browser, such as tabs, history, bookmarks, custom CSS, light and dark modes, etc.
